# aura-connect
##Requisitos Funcionais (RF)

(Tudo que o sistema DEVE fazer — funcionalidades)

RF01 – Cadastro de Usuário

O sistema deve permitir que alunos, professores e coordenadores realizem cadastro com nome, e-mail institucional e senha.

RF02 – Autenticação de Usuário

O sistema deve permitir login com validação de e-mail institucional e senha.

RF03 – Recuperação de Senha

O sistema deve permitir que o usuário solicite redefinição de senha por e-mail institucional.

RF04 – Exibir Feed de Comunicados Acadêmicos

O sistema deve exibir um feed com avisos, comunicados, tarefas e notificações oficiais das disciplinas.

RF05 – Filtrar Comunicados por Disciplina

O usuário deve conseguir filtrar os comunicados pelas disciplinas em que está matriculado.

RF06 – Envio de Comunicados pelos Professores

Professores devem poder criar, editar e publicar novos comunicados.

RF07 – Sistema de Notificações Internas

O sistema deve enviar notificações internas aos usuários sempre que houver novos comunicados ou alterações importantes.

RF08 – Página de Disciplinas/Turmas

O sistema deve exibir a lista de disciplinas do aluno ou professor, com acesso rápido aos comunicados de cada uma.

RF09 – Área do Usuário (Perfil)

O sistema deve permitir que o usuário visualize e edite informações básicas do seu perfil.

RF10 – Painel do Professor/Coordenação

Professores e coordenação devem ter acesso a funcionalidades administrativas, como:

postar avisos

editar avisos

excluir avisos

visualizar engajamento do aluno

RF11 – Integração com APIs externas (opcional)

O sistema deve permitir integração com Moodle, e-mail institucional ou WhatsApp, quando possível.

RF12 – Histórico de Avisos

O sistema deve manter um histórico dos comunicados publicados para que o usuário possa consultar posteriormente.

RF13 – Pesquisar Avisos

O usuário deve conseguir buscar avisos por palavra-chave.

RF14 – Feedback sobre notificações

O aluno poderá marcar uma notificação como lida, não lida ou importante.
